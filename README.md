#  AI Based Resume generator

**AI Based Resume generator** is an AI-powered resume builder that creates a professional, personalized resume from a user's profile, skills, experience, projects, education, and other information.

It uses **Google Gemini AI** to intelligently generate and optimize resume content while keeping the information grounded in the user's actual data.

## ✨ Features

* 🤖 AI-powered resume generation using Gemini
* 📄 Multiple resume templates — Modern, Minimal & ATS
* ✏️ Edit resume directly in the preview
* 📥 Download resume as PDF
* 🎯 ATS-friendly resume content
* 💻 Skill-based resume optimization
* 📱 Responsive React frontend
* ⚡ Redux & RTK Query for state management and API handling

## 🛠️ Tech Stack

**Frontend**

* React
* Redux Toolkit
* RTK Query
* CSS

**Backend**

* Java
* Spring Boot
* Google Gemini API

## 🚀 How It Works

```text
User Profile
     ↓
Resume Configuration
     ↓
Gemini AI
     ↓
Generated Resume
     ↓
Edit & Customize
     ↓
Download PDF
```

## 📌 Project Goal

AI Based Resume generator focuses on **generating the actual resume content**, not just providing a resume template. It analyzes the user's available information and transforms it into a professional, structured, and ATS-friendly resume.
